# Character endings

Each summit map plays `endings/<character>.mp4` when that character reaches the top. The files are
`capy`, `yoru`, `tico`, `piko` and `chang`, plus `group.mp4` for an online race win, and
`endings/<character>.jpg` is used as the poster frame. While a file is missing, the in-game summit
celebration is the ending.

How to make them with Grok Imagine (prompts, ffmpeg export settings): [`docs/ENDINGS-GROK.md`](../docs/ENDINGS-GROK.md).
